Простейшие тригонометрические уравнения

Урок посвящен изучению базовых принципов решения тригонометрических уравнений, а также применению метода разложения на множители.

Цели обучения:

  • 10.2.3.8 уметь решать простейшие тригонометрические уравнения;
  • 10.2.3.9 уметь решать тригонометрические уравнения с помощью разложения на множители.

Теоретическая часть

1. Формулы корней простейших уравнений

Уравнение $\sin x = a$

При $|a| \le 1$:

$$x = (-1)^n \arcsin a + \pi n, \quad n \in \mathbb{Z}$$

Уравнение $\cos x = a$

При $|a| \le 1$:

$$x = \pm \arccos a + 2\pi k, \quad k \in \mathbb{Z}$$

Уравнение $\text{tg } x = a$

Для любого $a \in \mathbb{R}$:

$$x = \text{arctg } a + \pi n, \quad n \in \mathbb{Z}$$

Уравнение $\text{ctg } x = a$

Для любого $a \in \mathbb{R}$:

$$x = \text{arcctg } a + \pi n, \quad n \in \mathbb{Z}$$

2. Частные случаи для синуса и косинуса

Значение $a$ $\sin x = a$ $\cos x = a$
0 $$x = \pi n$$ $$x = \frac{\pi}{2} + \pi n$$
1 $$x = \frac{\pi}{2} + 2\pi n$$ $$x = 2\pi n$$
-1 $$x = -\frac{\pi}{2} + 2\pi n$$ $$x = \pi + 2\pi n$$

* Во всех формулах предполагается, что $n \in \mathbb{Z}$ (множество целых чисел).

3. Решение уравнений методом разложения на множители

Метод разложения на множители заключается в том, чтобы перенести все члены уравнения в одну часть и представить полученное выражение в виде произведения, равного нулю. Произведение равно нулю тогда и только тогда, когда хотя бы один из множителей равен нулю (а другие при этом имеют смысл).

Пример:

Решите уравнение: $2\sin^2 x - \sin x = 0$

1. Выносим общий множитель $\sin x$ за скобки:

$\sin x (2\sin x - 1) = 0$

2. Приравниваем каждый множитель к нулю:

Первый случай:

$\sin x = 0$

$x = \pi n, n \in \mathbb{Z}$ (частный случай)

Второй случай:

$2\sin x - 1 = 0 \implies \sin x = \frac{1}{2}$

$x = (-1)^k \arcsin(\frac{1}{2}) + \pi k$

$x = (-1)^k \frac{\pi}{6} + \pi k, k \in \mathbb{Z}$

Практические задания

Решите уравнения самостоятельно, а затем проверьте себя, открыв решение.

Базовое уравнение

Решите уравнение:

$$\cos x = \frac{\sqrt{2}}{2}$$
Решение:

Используем общую формулу для косинуса: $x = \pm \arccos a + 2\pi k$

$$x = \pm \arccos\left(\frac{\sqrt{2}}{2}\right) + 2\pi k$$

Так как $\arccos\left(\frac{\sqrt{2}}{2}\right) = \frac{\pi}{4}$, получаем:

Ответ: $x = \pm \frac{\pi}{4} + 2\pi k, k \in \mathbb{Z}$
Сложный аргумент

Решите уравнение:

$$\sin\left(2x - \frac{\pi}{4}\right) = 1$$
Решение:

Это частный случай синуса ($\sin t = 1 \implies t = \frac{\pi}{2} + 2\pi n$).

Пусть $t = 2x - \frac{\pi}{4}$. Тогда:

$$2x - \frac{\pi}{4} = \frac{\pi}{2} + 2\pi n$$

Перенесем $-\frac{\pi}{4}$ в правую часть:

$$2x = \frac{\pi}{2} + \frac{\pi}{4} + 2\pi n$$

$$2x = \frac{3\pi}{4} + 2\pi n$$

Разделим обе части на 2:

$$x = \frac{3\pi}{8} + \pi n$$

Ответ: $x = \frac{3\pi}{8} + \pi n, n \in \mathbb{Z}$
Разложение на множители

Решите уравнение:

$$2\cos^2 x + \cos x = 0$$
Решение:

Вынесем общий множитель $\cos x$ за скобки:

$$\cos x(2\cos x + 1) = 0$$

Произведение равно нулю, когда хотя бы один множитель равен нулю:

1) $\cos x = 0$

Частный случай:

$x = \frac{\pi}{2} + \pi k, k \in \mathbb{Z}$

2) $2\cos x + 1 = 0$

$\cos x = -\frac{1}{2}$

$x = \pm \arccos(-\frac{1}{2}) + 2\pi n$

$x = \pm \frac{2\pi}{3} + 2\pi n, n \in \mathbb{Z}$

Ответ: $x_1 = \frac{\pi}{2} + \pi k, \quad x_2 = \pm \frac{2\pi}{3} + 2\pi n, \quad k,n \in \mathbb{Z}$
Группировка

Решите уравнение:

$$\sin x \cdot \cos x - \sin x + \cos x - 1 = 0$$
Решение:

Сгруппируем слагаемые попарно: первое со вторым, и третье с четвертым.

$$(\sin x \cdot \cos x - \sin x) + (\cos x - 1) = 0$$

Из первой скобки вынесем $\sin x$:

$$\sin x(\cos x - 1) + 1\cdot(\cos x - 1) = 0$$

Теперь вынесем общую скобку $(\cos x - 1)$:

$$(\cos x - 1)(\sin x + 1) = 0$$

1) $\cos x - 1 = 0$

$\cos x = 1$ (частный случай)

$x = 2\pi k, k \in \mathbb{Z}$

2) $\sin x + 1 = 0$

$\sin x = -1$ (частный случай)

$x = -\frac{\pi}{2} + 2\pi n, n \in \mathbb{Z}$

Ответ: $x_1 = 2\pi k, \quad x_2 = -\frac{\pi}{2} + 2\pi n, \quad k,n \in \mathbb{Z}$
